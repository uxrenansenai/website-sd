# SENAI Soluções Digitais

Implementação em React, TypeScript e Vite do layout fornecido para o site SENAI Soluções Digitais.

## Executar

```bash
npm install
npm run dev
```

Valide o build com `npm run build`.

## Estrutura

- `src/components`: seções e elementos reutilizáveis.
- `src/styles/global.css`: tokens visuais, layout e media queries.
- `src/styles/motion.ts`: variantes compartilhadas de Framer Motion.
- `public/reference.png`: captura fornecida, usada para preservar as imagens e marcas enquanto os assets individuais do Figma não estão acessíveis.

O formulário abre o aplicativo de e-mail com os dados preenchidos. Para envio direto pelo site, será necessário conectar um serviço de formulário ou backend.
